# Verificación Funcional de Circuitos Digitales con Python

**Introducción a UVM usando pyUVM, cocotb y GitHub Codespaces**

Repositorio del curso. Construye una infraestructura reproducible para
practicar verificación funcional de RTL Verilog con herramientas de
código abierto, ejecutable directamente en GitHub Codespaces.

## Estado

🚧 En construcción. El repositorio se está montando de forma incremental.
